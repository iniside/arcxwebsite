CSS support¶

What ArcRmlUI does with the CSS a web page uses. A document is drawn by RmlUi, a UI library, so its style sheets (.rcss files, written in RCSS) follow RmlUi's rules, not a browser's. The tables list what the plugin supports. For a walk through the differences by topic see Coming from HTML and CSS.

Status words in the tables:

  • supported: RmlUi lays out, paints or acts on the value.
  • partial: works for the values or forms the Notes list.
  • parsed, no effect: accepted without a warning, but nothing on screen changes.
  • RmlUi-only: not CSS, an extension RmlUi adds; the Notes say what it does.

A declaration the engine drops is logged as a warning, see Validation.

Properties¶

Every property takes inherit, initial and unset; see CSS-wide keywords.

Box model¶

Property Status Notes
margin, padding and their four sides supported margin takes auto.
border-width, border-color and the side forms, border supported
border-style and the side forms partial none, solid, dashed, dotted, inset, outset, hidden. No double, groove, ridge.
border-radius and the four corners supported
box-sizing supported content-box, border-box.
width, height, min-*, max-* supported Keywords auto, min-content, max-content, fit-content.
aspect-ratio supported
outline, outline-width, outline-color, outline-offset supported
outline-style partial none, solid, dashed, dotted. No auto.
margin-inline, margin-block, padding-inline, padding-block, inset-inline, inset-block, border-inline*, border-block* partial Aliases of the left/right or top/bottom sides, as are their -start / -end forms (margin-inline-start, border-block-end-color, border-start-end-radius, ...) and inline-size, block-size with their min- / max- forms. No writing modes: inline is always left to right, block top to bottom.

Input and scrolling¶

Property Status Notes
pointer-events partial none, auto.
cursor partial Twelve names map to a cursor of Slate, Unreal's UI framework: pointer, hand, text, move, ew-resize, col-resize, ns-resize, row-resize, not-allowed, grab, grabbing, crosshair. Any other value gives the arrow. Which cursor each shows: Mouse cursor.
user-select parsed, no effect
overscroll-behavior partial auto, contain.
scrollbar-width partial auto, thin, none.
scrollbar-color supported

RmlUi-only¶

Property Status Notes
decorator RmlUi-only Draws layers on an element, such as an image, a ninepatch or a gradient, written inline or named by an @decorator rule. Prefer background.
font-effect RmlUi-only Effects on text: blur, glow, outline, shadow. Prefer text-shadow.
fill-image RmlUi-only The image of the filled part of a progress bar.
image-color RmlUi-only The colour an img or a progress fill is tinted with; default white.
scrollbar-margin RmlUi-only Shortens the track of a scrollbar by this length, or by the other scrollbar's size when that is larger.
drag RmlUi-only Whether and how an element can be dragged: none (default), drag, drag-drop, block, clone; see Drag and drop.
focus RmlUi-only auto (default) or none; with none the element and its descendants do not take focus.
nav, nav-up, nav-right, nav-down, nav-left, tab-index RmlUi-only tab-index (none or auto) and nav decide whether an element is a stop for the arrow keys and where each arrow goes. The default style sheet gives its controls nav: auto; a div or span needs tab-index: auto; nav: auto to be a stop; see Navigation.
-rmlui-direction, -rmlui-language, -rmlui-object-position-*, -rmlui-scrollbar-*-color RmlUi-only Longhands behind object-position and scrollbar-color, and the text direction and language of an element.

Not supported¶

Common properties a web developer looks for that do not exist. The list is not every CSS property; a declaration of one is dropped with the warning "unknown property", except tab-size, resize, -webkit-text-size-adjust, -webkit-tap-highlight-color and font-variation-settings: normal, which are dropped silently.

Group Properties
Layout position: sticky, columns and column-*, table-layout, caption-side, empty-cells, contain, content-visibility, isolation, will-change, zoom, all
Writing writing-mode, direction (only -rmlui-direction), unicode-bidi, text-orientation
Text word-spacing, hyphens, line-break, tab-size, font-stretch, font-variant (shorthand), font-variation-settings, font-synthesis, font-optical-sizing, text-emphasis, text-rendering, -webkit-font-smoothing, -webkit-text-fill-color, -webkit-text-size-adjust, quotes, counter-reset, counter-increment
Shapes and images clip-path, border-image, shape-outside, background-blend-mode, mask-type, mask-mode, image-rendering
Scrolling scroll-behavior, scroll-snap-*, scroll-padding, scroll-margin, scrollbar-gutter, overflow-clip-margin
Containers and motion container, container-type, container-name, animation-timeline, animation-composition, view-transition-name, offset-path
Interaction resize, touch-action, caret-shape, field-sizing, color-scheme, forced-color-adjust, print-color-adjust, -webkit-tap-highlight-color
Aliases grid-gap, grid-row-gap, grid-column-gap, line-clamp

A value that is not accepted by a supported property is dropped the same way, with "invalid value". The ones web developers meet: outline: auto, appearance: button, min-height: 1lh.

Unit Status Notes
px, %, em, rem, in, cm, mm, pt, pc supported px is multiplied by the DPI scale: CSS px and dp.
vw, vh, vmin, vmax supported
svw, svh, lvw, lvh, dvw, dvh partial Same as vw and vh: a game has no toolbar that changes the viewport.
deg, rad supported Angles.
s, ms partial Only in transition-* and animation-* times.
fr partial Only in grid track lists.
x, dppx supported Resolution, in @media.
dp RmlUi-only Density-independent pixel. Layout extension. Prefer px.
ex, ch, lh, cq* not supported The declaration is dropped.
turn, grad partial Only as the hue of a colour function such as hsl(); in any other value the declaration is dropped.

Syntax Status Notes

env() not supported
Colours: hex, rgb(), rgba(), hsl(), hsla(), lab(), lch(), oklab(), oklch(), named colours, transparent, currentcolor supported

Selectors¶

Selector Status Notes
Type, class, id, *, attribute [a], =, ~=, \|=, ^=, $=, *= partial Values match case-sensitively; the i case flag is not supported.
Descendant, >, +, ~ supported
Nesting with & supported
:nth-child(), :nth-last-child(), :nth-of-type(), :nth-last-of-type(), :first-child, :last-child, :first-of-type, :last-of-type, :only-child, :only-of-type, :empty, :root, :scope supported
:not(), :is(), :where(), :dir() supported
:hover, :active, :focus, :focus-visible, :focus-within, :checked, :disabled, :enabled, :placeholder-shown, :required, :optional, :read-only, :read-write supported
:selected, :drag RmlUi-only
:has(), :target, :visited, :valid, :invalid, :link and any other name never matches The rule is kept; no element ever has that state. The validator reports it as an unknown pseudo-class, except vendor-prefixed names (-webkit-, -moz-, -ms-, -o-), :host, ::backdrop and ::file-selector-button, which are silent outside a :not() argument.

Pseudo-elements¶

Pseudo-element Status Notes
::before, ::after supported With content.
::placeholder supported On text fields.
::-webkit-scrollbar, -track, -thumb, -corner supported
::-webkit-slider-runnable-track, ::-webkit-slider-thumb supported On input type="range".
::first-line, ::first-letter, ::selection, ::marker, ::backdrop, ::file-selector-button never matches

At-rules¶

At-rule Handling Notes
@media supported Features width, height, aspect-ratio, orientation, resolution, hover, any-hover, pointer, any-pointer, color, prefers-reduced-motion, prefers-color-scheme, prefers-contrast, prefers-reduced-transparency, forced-colors, update, scripting and the range syntax. Types all and screen.
@keyframes, @font-face, @supports, @property supported
@decorator RmlUi-only Defines a decorator.
@spritesheet RmlUi-only
@starting-style skipped silently The block is skipped.
@charset, @namespace skipped silently
@layer a, b;, @layer name { ... } supported Layers order the cascade as in Chrome: a later layer beats an earlier one, unlayered rules beat every layer, and !important reverses both. A document has one layer order, by first appearance across its sheets. An invalid name warns.
@container applied without the condition, warns The rules apply to every element, in the order written, with the warning "Unknown at-rule". A container query is never evaluated.
@import not followed Warns; link each sheet from the document.
Any other at-rule top level: applied without the condition, warns; inside a style rule: dropped, warns At top level the same as @container. Nested in a style rule it is dropped with "At-rule '@...' inside a style rule is dropped."

Rules inside @container blocks apply to every element, as if the wrapper were not there: a container condition is never checked.

CSS-wide keywords¶

Keyword Status
inherit, initial, unset supported, also on shorthands
!important supported
revert, revert-layer not supported

Validation¶

The validator compiles RML documents and RCSS style sheets and checks them against the project: view model classes, fields and functions, images, fonts, localization keys and input mappings. It finds in the editor what would otherwise show up as a log line when a document opens. A run needs the editor.

Run it¶

Content Browser. Select documents, style sheets or folders, and choose Validate RML in the context menu. A notification shows the summary line, ArcRmlValidate: N files, 0 errors, 0 warnings. Its Show Message Log link (a button when the run has errors) opens the Message Log window on the page Validate of the ArcRmlUI log. A run without problems has only the summary line on that page; every other line is a diagnostic.

Console. In the editor, open the console and type:

ArcRml.Validate <Path> [<Path> ...]

A path is a file or a folder on disk, relative to the project folder, and must be under a content root. The result goes to the same Message Log page.

Commandlet. For a build machine. UnrealEditor-Cmd.exe is in the Engine/Binaries/Win64 folder of your Unreal Engine install:

UnrealEditor-Cmd.exe "<Project>.uproject" -run=ArcRmlValidate -Paths="<Path>;<Path>" -WarningsAsErrors -json="<File>"
Argument Effect
-Paths= Disk paths separated by ;, relative to the folder you run the command from, not the project folder. Without it the whole tree of every content root is validated. A path under no content root fails the run.
-WarningsAsErrors A warning also fails the run.
-json="<File>" Also writes the result as JSON: a summary of files, errors and warnings, the roots, and per diagnostic file, line, severity, code and message.

Each diagnostic prints as <file>(<line>): <severity> <kind>: <message>, followed by a summary line ArcRmlValidate: N files, N errors, N warnings. For example:

C:/MyProject/Content/UI/Rml/Menu.rml(12): error unknown-field: 'Helth' on model 'player' reads 'Helth', which 'PlayerViewModel' does not have

The exit code is 0, or 2 when there is an error, a warning with -WarningsAsErrors, a path under no content root, or a check that did not run.

What it reports¶

Every diagnostic has a severity (error or warning) and a kind. The kinds a project meets most:

Kind Meaning
unknown-field A binding reads a field the declared view model does not have.
unknown-function, call-arity call() names a function the model does not have, or passes the wrong number of arguments.
view-model-path A path source cannot work; see below.
unknown-class, view-model-create A <viewmodel class> does not load, or is abstract and cannot be created.
unknown-resolver, unknown-resolver-property A resolver class is unknown, or an attribute names no property of it.
head A <meta> or <viewmodel> in <head> is invalid.
input-mapping An input-mapping does not load as an Input Mapping Context, or a menu document has no key on the Back action.
missing-image, missing-font, unknown-font-family An image or font file is not found under a content root, or a font family has no @font-face.
missing-document An open: target is not an RML document.
missing-loc-key A localization key has no entry in its string table.
structural-conflict For example data-if and data-for on one element, or data-action without a data-model on <body>.
undefined-variable, duplicate-id An RCSS variable is used and never defined; two elements share an id.
component A dc-import component problem.
data-expression A data expression does not parse (warning).

Other kinds come from the RCSS and RML compile (unknown property, invalid value, invalid selector, XML syntax, and similar), and from converting HTML into RML. A CSS declaration the engine drops is one of them, with the warning "unknown property" or "invalid value"; CSS support lists what is dropped.

view-model-path¶

A path source reads the view model through a chain of properties, such as GetOwningPlayer.SampleViewModel (View models). The validator follows the chain with the types it can see, starting at UUserWidget, and reports:

  • A warning for a segment the visible type lacks. The live object may be a subclass that has it, so the check stops there and the model can still resolve at run time. The SourcePath sample gets this warning on SampleViewModel: GetOwningPlayer returns APlayerController, which has no SampleViewModel, and the model resolves when the game runs.
  • An error for a segment that is not readable or not an object, and for a last type unrelated to the declared class.

A misspelled segment gets the same warning and never resolves, with no other message, so read the segment name in the warning.

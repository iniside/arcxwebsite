Expression reference¶

The language of {{ }} in a document and of the binding attributes that take an expression: data-if, data-visible, data-class-*, data-style-*, data-attr-*, data-attrif-*, data-pulse-*, data-rml, data-value, data-checked, data-world and data-focus-request. A data-event-* holds statements made of the same expressions. data-for and data-alias-* take a path, not an expression.

Literals¶

Literal Form
Number Digits with at most one . and an optional leading -: 3, 0.25, 5., -.5, -2; a number cannot start with . and has no exponent. Every number is a double.
Text Single quotes: 'Red'. \' is a quote and \\ a backslash; any other backslash stays as it is.
Boolean true, false.

Names and paths¶

A name starts with a letter and goes on with letters, digits, _ and .. Player.Name reads a member, Items[0] or Items[i + 1] an element (the index is cut to a whole number), Items.size the length of an array. ev.<name> reads a parameter of the event in a data-event-* (event reference); a parameter the event does not carry is empty.

The first name of a path is looked up as a field of the view model, then as a data-alias-* or data-for name of the element or an ancestor, then as a field whose name differs only in case. When two fields match that way, a warning names both and the one used.

Operators¶

From the strongest binding to the weakest. Operators of one row run left to right.

Differs from JavaScript

  • &&, || and the transform | share one level: a || b && c is (a || b) && c, and a && b | f is (a && b) | f. Use parentheses. Both sides of && and || are always evaluated.
  • - before a name is an error; - belongs to a number literal only. Write 0 - Count. There is no %.
  • == compares text when either side is text (Types and conversion).
Operators Meaning
( ), ! Grouping; ! negates the operand right after it, so !a == b is (!a) == b.
*, / Multiply, divide.
+, - Add or join text, subtract.
==, !=, <, <=, >, >= Compare.
&&, \|\|, \| And, or, transform: one level.
? : Condition.
  • c ? x : y evaluates only the chosen branch. Each branch reaches as far as it can: c ? a : b | f is c ? a : (b | f), and x | f ? a : b is (x | f) ? a : b. a ? 'x' : b ? 'y' : 'z' chains.

Types and conversion¶

Where Rule
+ Joins text when either side is text, the other side converted; otherwise adds numbers.
-, *, /, <, <=, >, >= Numbers. Text becomes the number it starts with, or 0 ('abc' is 0); true is 1.
==, != Compare text when either side is text, else numbers: Count == '3' is true when Count is 3.
True or false (!, &&, \|\|, ? :, data-if, data-visible, data-class-*, callIf) A number is true when not 0. Text is true only when it is true or 1 in any case; other text, also a name like 'Bob', is false. An empty value is false.
Printed as text A boolean prints 1 or 0, so bEven == 'true' is false. An integer field prints as it is. Any other number, also the result of an operator, prints with at most three decimals and no trailing zeros: 1 / 3 prints 0.333, Count + 1 prints 4 when Count is 3.

Transforms¶

value | name(arguments) passes the value as the first argument; value | name needs no parentheses without further arguments. name(value, arguments) is the same call. A transform given the wrong arguments returns an empty value; the ones marked "logs" also write a warning.

Transform Result
to_lower, to_upper The value as text, in lower or upper case.
format(n), format(n, true) The number with n (0 to 32) digits after the point; true removes trailing zeros. A wrong argument count or precision logs a warning; a value that is not a number or a bad third argument gives an empty value silently.
round The nearest whole number; halves round up.
arcclamp(low, high) The number limited to the range.
arcmin(other), arcmax(other) The smaller or the larger of the two numbers.
arcnum, arcnum(d) The number with digit grouping and exactly d decimals (0 to 18, default 0), in the game's language, halves to even. Text is not a number here. Logs once.
arcpct, arcpct(d) The value times 100 as a percent, in the game's language, otherwise as arcnum. Logs once.
arctime Seconds, rounded up and at least 0, as mm:ss, or h:mm:ss from one hour. Logs once.
arcplural('Key') The plural form of a String Table entry for the number (Localization). Logs once.
arcsince Seconds from the value, a time taken with ArcRmlClock::Seconds() (C++, module ArcRmlUIData, header ArcRmlClock.h), to the moment the binding is evaluated.

Event statements¶

A data-event-* holds statements separated by ;, run left to right. Each statement is a function call: call, callIf or stopPropagation (Events). A name without parentheses calls with no arguments: stopPropagation is stopPropagation(). Arguments are expressions, transforms included. The example is not from a sample: the line sits in a document inside an element whose data-model names a view model, the '' in call means that model, and SetVolume is a function of it:

<input type="range" data-event-change="call('', 'SetVolume', ev.value | arcclamp(0, 1))"/>

Name = expression parses but always fails when it runs: a document never writes a view model field. Any other function name fails the same way.

Errors¶

What you see, and the cause.

What you see Cause and what happens
The binding or handler does nothing. The validator reports Data expression '<expression>' does not parse: <message>. A syntax error. The document compile reports a data-expression diagnostic (Validation) in a build that is not a Shipping build; the ArcRmlValidate commandlet reports it as a warning. Documents load compiled, so the run time logs nothing: the binding or handler is not created, and the diagnostic is the only report. A Shipping build reports nothing.
A log line Could not find variable name '<address>' in data model., with the whole address (Player.Name) An unknown name. The binding is not created.
Log lines Error during execution. <message> and Failed to execute program with <n> instructions: with a dump of the program An unknown transform or event function, an assignment, or an index that is not a number. A binding keeps its last value; the statements after the failing one do not run.
Nothing is logged; the value prints nothing and is false A transform given wrong arguments: the value is empty.

Messages from RmlUi appear in LogArcRmlUI, prefixed RmlUi:: RmlUi errors as errors, RmlUi warnings as warnings.
